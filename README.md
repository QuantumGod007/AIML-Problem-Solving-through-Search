# AIML-Problem-Solving-through-Search# AIML Problem Solving through Search

## Practical Assignment 2

This project evaluates different AI search techniques using a graph-search problem and the 8-Queens problem.

## Algorithms Implemented

### Uninformed Search
- BFS
- DFS
- Uniform Cost Search

### Informed Search
- Greedy Best First Search
- A* Search

### Local Search
- Hill Climbing
- Simulated Annealing

### Constraint Satisfaction
- Backtracking
- Forward Checking

## Performance Metrics

The algorithms are compared using:

- Path cost
- Nodes / states explored
- Execution time
- Final conflicts

## Problems Used

### Graph Search
A custom graph is used to compare BFS, DFS, UCS, Greedy and A*.

### 8-Queens
The 8-Queens problem is solved using Hill Climbing, Simulated Annealing, Backtracking and Forward Checking.
